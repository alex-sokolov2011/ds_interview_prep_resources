# 🤖 Тренажёр с Multiple Choice вопросами по Python и ML

Добро пожаловать! Если вы готовитесь к техническому собеседованию на позицию Data Scientist, ML-инженера или аналитика данных — этот раздел поможет вам структурированно повторить ключевые темы и проверить себя с помощью интерактивных тестов.

Здесь собраны вопросы в формате multiple choice, разбитые по темам (Python, ML, статистика и др.) — удобно для регулярной практики и поиска пробелов

---

## 🔍 Что входит в раздел `interview_mcq_trainer/`

### 📘 `mcq_trainer.ipynb`  
Интерактивный тренажёр с вопросами в формате multiple choice.  
Выбираете тему — отвечаете — получаете фидбек и статистику.  
Работает локально в Jupyter — без необходимости устанавливать отдельное ПО.
