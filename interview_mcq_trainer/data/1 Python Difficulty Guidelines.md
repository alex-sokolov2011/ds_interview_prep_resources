# Руководство по оценке сложности вопросов Python для MCQ
Цель - сделать присвоение уровней объективным и воспроизводимым, не выходя за рамки локальных артефактов проекта.

## Оси сложности и баллы
Оцени вопрос по пяти осям. Складывай баллы в суммарный счет.
- A1 Syntax and core constructs: 0-2
  - 0 - примитивный факт синтаксиса, без кода
  - 1 - короткий фрагмент кода без подвохов
  - 2 - несколько синтаксических идей вместе (напр., LEGB + comprehension)
- A2 Stdlib и идиомы: 0-3
  - 0 - не требуется стандартная библиотека или идиома
  - 1 - очень распространенная идиома или базовый модуль
  - 2 - менее частая идиома или несколько модулей вместе
  - 3 - редкая идиома/протокол, требующий уверенного владения
- A3 Логика и рассуждение: 0-3
  - 0 - ответ из одного шага
  - 1 - 2 шага рассуждения
  - 2 - 3-4 шага, требуется мысленный трекинг состояния
  - 3 - многошаговая логика
- A4 Крайние случаи и отладка: 0-2
  - 0 - нет ловушек
  - 1 - один крайний случай/типичная ловушка
  - 2 - два и более крайних случая или взаимодействующих ловушек
- A5 Контекст исполнения и окружение: 0-1
  - 0 - не зависит от окружения
  - 1 - зависит от версии, порядка вычисления, интерпретатора или perf-подхода

## Правила агрегирования в уровень
- Сумма = A1+A2+A3+A4+A5
- Мэппинг уровней:
  - L1: 0-2
  - L2: 3-4
  - L3: 5-6
  - L4: 7-8
  - L5: 9-11
- Тайбрейкер:
  - Если A4>=2 или A5=1 - повысить уровень на 1
  - Если сумма на нижней границе и A4=0 и A5=0 - понизить уровень на 1
- Типичное время ответа по уровням (сек): L1 30, L2 60, L3 90, L4 120, L5 150

## Якорные примеры и признаки
Используй эти «якоря» как эталоны при разметке. Они описывают тип задач, а не конкретные формулировки.

### L1
- Якоря: прямой вопрос по синтаксису; простое чтение мини-кода без подвохов; базовые типы и операции
- Признаки: один факт, ответ почти без расчетов, нет ловушек

#### Пример для уровня L1 (Python)

**Вопрос:**
Какой тип будет у переменной после выполнения кода `x = 5 / 2` в Python 3?

##### Разбор сложности по осям

* A1 Syntax and core constructs: **1**
  Короткий фрагмент кода, знание базовой семантики деления `/` в Python 3
* A2 Stdlib и идиомы: **0**
  Стандартная библиотека и идиомы не требуются
* A3 Логика и рассуждение: **0**
  Ответ из одного шага, без пошаговой трассировки
* A4 Крайние случаи и отладка: **0**
  Ловушек и крайних случаев нет (вопрос явно про Python 3)
* A5 Контекст исполнения и окружение: **0**
  Контекст указан в формулировке, доп. зависимостей нет

**Сумма:** 1
**Уровень по правилам:** L1 (диапазон 0–2)
Тайбрейкеры не срабатывают (A4=0, A5=0).
Ориентир по времени ответа из шкалы: \~30 сек.

**Итог:** вопрос соответствует уровню сложности **L1**.

### L2
- Якоря: простая идиома из stdlib; один нестандартный момент в коде; простая работа с коллекциями
- Признаки: требуется небольшое рассуждение или знание типичной идиомы

#### Пример для уровня L2

**Вопрос:**
Чем `is` отличается от `==` в Python и в каких случаях результат может отличаться?

##### Разбор сложности по осям

* A1 Syntax and core constructs: **1**
  Базовое знание различия идентичности объектов и сравнения на равенство
* A2 Stdlib и идиомы: **0**
  Стандартные модули и идиомы не требуются
* A3 Логика и рассуждение: **1**
  Короткое рассуждение о поведении для разных типов и перегрузке `__eq__`
* A4 Крайние случаи и отладка: **1**
  Один типичный подвох: интернирование неизменяемых объектов и случаи, когда `a is b` может неожиданно быть True или False
* A5 Контекст исполнения и окружение: **0**
  Детали реализации можно упомянуть, но для ответа не обязательны

**Сумма:** 3
**Уровень по правилам:** L2 (диапазон 3–4)
Тайбрейкеры не срабатывают (A4=1, A5=0).
Ориентир по времени ответа из шкалы: \~60 сек.

**Итог:** вопрос соответствует уровню сложности **L2**.

### L3
- Якоря: кусок кода с одним подвохом; комбинирование двух идей; аккуратный учет порядка выполнения
- Признаки: нужно шаг за шагом проследить состояние, 2-3 шага логики

#### Пример для уровня L3

**Вопрос:**
Что выведет следующий код и почему?

```
def func(x=[]):
    x.append(1)
    return x
print(func())
print(func())
```

Ожидаемый вывод:

```
[1]
[1, 1]
```

##### Разбор сложности по осям

* A1 Syntax and core constructs: **2**
  Функция с параметром по умолчанию, список, метод `.append`, два вызова функции
* A2 Stdlib и идиомы: **0**
  Внешние модули и идиомы не требуются
* A3 Логика и рассуждение: **2**
  Нужно пошагово отследить состояние аргумента между двумя вызовами
* A4 Крайние случаи и отладка: **2**
  Две взаимодействующие ловушки: изменяемое значение по умолчанию и то, что значения по умолчанию вычисляются один раз при определении функции
* A5 Контекст исполнения и окружение: **0**
  Зависимости от окружения нет

**Сумма:** 6
**Уровень по правилам:** L3 (диапазон 5–6)
Тайбрейкеры не срабатывают (A4=2, но сумма уже в диапазоне L3).
Ориентир по времени ответа из шкалы: \~90 сек.

**Итог:** вопрос соответствует уровню сложности **L3**.

### L4
- Якоря: два взаимодействующих подвоха; нетривиальные части stdlib; преобразования с граничными эффектами
- Признаки: повышенная вероятность ошибки, требуется опыт распознавания ловушек


#### Пример для уровня L4

**Вопрос:**
Рассмотрим следующий Python код.
Каким будет результат выполнения и почему?

```
def update_tuple_with_list(t):
    t[0].append(4)
    t = (1, 2, 3)

my_tuple = ([1, 2, 3], 'a', 'b')
update_tuple_with_list(my_tuple)
print(my_tuple)
```

Ожидаемый вывод:

```
([1, 2, 3, 4], 'a', 'b')
```

##### Разбор сложности по осям

* A1 Syntax and core constructs: **2**
  Понимание функций, кортежей, списков, индексирования и мутации списка методом `.append`
* A2 Stdlib и идиомы: **0**
  Внешние модули не нужны
* A3 Логика и рассуждение: **3**
  Многокроковая цепочка рассуждений:

  1. параметр `t` ссылается на исходный кортеж
  2. `t[0]` возвращает вложенный список
  3. `append(4)` мутирует сам список, а не кортеж
  4. присваивание `t = (1, 2, 3)` лишь переназначает локальное имя
  5. у вызывающей стороны кортеж остался тем же объектом, но его первый элемент уже изменен
* A4 Крайние случаи и отладка: **2**
  Две взаимодействующие ловушки: «иммутабельный кортеж с мутабельным содержимым» и «локальная переназначаемость имени аргумента не меняет объект у вызывающего кода»
* A5 Контекст исполнения и окружение: **0**
  От окружения не зависит

**Сумма:** 2 + 0 + 3 + 2 + 0 = **7**
**Уровень по правилам:** **L4** (диапазон 7–8). Тайбрейкеры не требуются.
Ориентир времени ответа: около 120 сек.

**Итог:** вопрос соответствует уровню сложности **L4**

### L5
- Якоря: редкие идиомы/протоколы; несколько взаимосвязанных ловушек; скрытые эффекты порядка вычислений
- Признаки: высокая стоимость ошибки, комплексная логика, взаимодействие контекста исполнения

#### Пример для уровня 5 (Python)

**Вопрос:**
Что выведет следующий код и почему?

```python
import asyncio, time

async def sleeper():
    time.sleep(1)
    return 'done'

async def main():
    start = time.time()
    await asyncio.gather(*(sleeper() for _ in range(5)))
    print(round(time.time() - start))

await main()
```

Ожидаемый вывод:

```
5
```

(округлённое время около 5 секунд)

##### Разбор сложности по осям

* A1 Syntax and core constructs: **2**
  Понимание async/await, `gather`, генератора корутин
* A2 Stdlib и идиомы: **3**
  Семантика `asyncio`, модель задач и шагов event loop, отличие блокирующего `time.sleep` от `asyncio.sleep`
* A3 Логика и рассуждение: **3**
  Многокроковая цепочка:

  1. создаются 5 корутин `sleeper()`
  2. `gather` планирует их как задачи
  3. первая задача стартует и сразу выполняет блокирующий `time.sleep(1)`
  4. event loop блокируется на 1 секунду, остальные задачи не выполняются
  5. по очереди каждая задача блокирует ещё на 1 секунду → суммарно \~5 секунд
* A4 Крайние случаи и отладка: **2**
  Ловушки: блокирующий вызов внутри корутины, ложное ощущение параллелизма с `gather`
* A5 Контекст исполнения и окружение: **1**
  Топ-левел `await` допустим в Jupyter, а в скрипте нужен `asyncio.run(main())`

**Сумма:** 2 + 3 + 3 + 2 + 1 = **11**
**Уровень по правилам:** **L5** (диапазон 9–11). Тайбрейкер A5=1 подтверждает верхнюю границу.
Ориентир времени ответа: \~150 сек.

**Итог:** вопрос соответствует уровню сложности **L5**
